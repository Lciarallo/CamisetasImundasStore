# ⚡ Camisetas Imundas Store — E-commerce Streetwear Underground

> **Vestindo o Caos | Estilo Underground & Streetwear Sem Filtro**

Plataforma e-commerce moderna e responsiva construída com React, Vite e TypeScript. Desenvolvida com estética streetwear arrojada (dark mode com sotaque verde ácido `#ccff00`), micro-interações fluidas e sistema completo de carrinho e checkout.

---

## 🚀 Tecnologias Utilizadas

- **Core**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Estilização**: Vanilla CSS com variáveis de design system, Glassmorphism e animações personalizadas.
- **Iconografia**: [Lucide React](https://lucide.dev/)
- **Efeitos**: `canvas-confetti` para celebração no checkout.

---

## 🎨 Funcionalidades

- **Design System Underground**: Estética gótica e streetwear de ponta com cartões glassmorphism, sombras neon e tipografia marcante (`Syne` + `Inter`).
- **Navegação & Filtros**: Busca em tempo real, ordenação por preço/avaliação e navegação por categorias (*Oversized*, *Vintage Trash*, *Graphic Tees*, *Edição Limitada*).
- **Cartão de Produto Interativo**: Seletor rápido de tamanho, botão de lista de desejos (heart toggle), badges promocionais e pré-visualização rápida.
- **Modal de Detalhes**: Exibição completa de especificações, composição do tecido, guia de tamanhos e seletor de quantidade.
- **Carrinho Lateral (Cart Drawer)**:
  - Calculadora de barra de progresso para **Frete Grátis** (compras acima de R$ 250).
  - Controle de quantidade e exclusão de itens.
  - Validador de cupons de desconto (ex: `IMUNDA10` e `IMUNDA20`).
- **Checkout Seguro Simulado**:
  - Formulário completo de dados do cliente e entrega.
  - Opções de pagamento via **PIX com QR Code instantâneo**, Cartão de Crédito e Boleto.
  - Animação de confete e confirmação de pedido com número de rastreio.

## 💻 Como Executar o Projeto

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/CamisetasImundasStore.git

# Acesse a pasta do projeto
cd CamisetasImundasStore

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

---

## 📦 Build para Produção

```bash
npm run build
```
